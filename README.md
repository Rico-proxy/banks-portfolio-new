# banks-portfolio

A portfolio website for Banks Studio and Banks, built with React Router, JSX, Tailwind CSS, and local shadcn-style UI primitives.

## Getting Started

Install the dependencies:

```bash
npm install
```

### Development

Start the development server with HMR:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

## Building for Production

Create a production build:

```bash
npm run build
```
